CPU-Rendered Mandelbrot Set

Overview

The Mandelbrot set is a set defined in the complex plane by the formula $f_c(z) = z^2 + c$, where $c$ is a complex number starting at z = 0 . The algorithm is then the sequence $f_c(0)$, $f_c(f_c(0))$, etc. For the Mandelbrot set, this function is evaulated for each pixel on the screen. If the number of iterations exceeds the max number of iterations (the function diverges at c), then the color is black. Otherwise, the number of iterations it took to become unbound is plotted as a color (HSV in the above picture). Since the Mandelbrot set is closed, values that exceed the radius $|Z_n| > 2$ are considered unbound.
