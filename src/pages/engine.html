Game Engine Written in C (WIP)

Overview

The culumination of all my experience with graphics and low level programming, this project will be a showcase of everything I've learned in CS over the last 4 years. Written entirely in C and only a few third party dependencies, this is the largest project I've attempted by myself. Features include:

  • Custom library (ctility) which provides data structure implementations, logging, strings, and custom memory allocation
  • Custom seralizer / deserializer for saving and loading scenes
  • Can switch between debug / release mode
